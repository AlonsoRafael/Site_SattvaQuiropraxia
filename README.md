# Sattva Saúde Integrativa

Projeto migrado para Next.js com App Router e exportação estática.

## Rodar localmente

```bash
npm install
npm run dev
```

## Build estático

```bash
npm run build
```

O build gera a saída em `out/`, pronta para hospedagem estática.

## Rotas

- `/` - página principal
- `/blog` - publicações do Instagram

## Estrutura principal

- `app/page.jsx`
- `app/blog/page.jsx`
- `app/globals.css`
- `components/HomeClient.jsx`
- `components/ResponsiveHeader.jsx`
- `public/imagens`
- `public/favicon_io`
